# Night Fury - College Go-Kart Racing Team Website

![Night Fury Logo](Image.png)

## 🏁 About

Night Fury is a college-based go-kart racing team website showcasing our journey of designing, building, and racing high-performance karts. This website serves as our digital presence, highlighting our team, achievements, and upcoming competitions.

## ✨ Features

### 🎯 Main Sections

1. **Hero/Landing Section**
   - Dynamic background with team go-kart image
   - Animated "NIGHT FURY" heading with glow effects
   - Team tagline: "Built For Speed. Driven By Passion."
   - Responsive design with parallax effects

2. **About Us Section**
   - Team mission and vision
   - What we do: Design, Build, Test, Race
   - Team statistics (Races Won, Team Members, Experience)
   - Animated stat cards with hover effects

3. **Team Section**
   - Team member profiles with photos
   - Roles and responsibilities
   - Social media links
   - Hover effects with overlay

4. **Competitions Section**
   - Past and upcoming races
   - Event details and locations
   - Status badges (Completed/Upcoming)
   - Interactive cards with animations

5. **Content Grid**
   - Membership information
   - Club details
   - Latest videos section

6. **Footer**
   - Quick links navigation
   - Contact information
   - Newsletter subscription
   - Social media links

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs directly in browser

### Installation

1. **Download/Clone the project**
   ```bash
   git clone <repository-url>
   cd nightfury
   ```

2. **Add your images**
   - Place `Image.png` (go-kart background) in the root folder
   - Place `Teamcoordinator.png` (team captain photo) in the root folder

3. **Open the website**
   - Simply double-click `index.html` or
   - Right-click and select "Open with" your preferred browser

## 🎨 Customization

### Update Team Information

**Team Statistics** (in `index.html`):
```html
<div class="stat-item">
    <h3>1</h3>
    <p>Race Won</p>
</div>
```

**Team Members** (in `index.html`):
```html
<div class="team-member">
    <h3>Your Name</h3>
    <p class="member-role">Your Role</p>
    <p class="member-bio">Your bio</p>
</div>
```

### Update Colors

**Primary Colors** (in `styles.css`):
